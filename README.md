# Personal Warranty Tracker

A simple Python command-line application to manage product warranties.
Users can add products, store purchase and warranty expiry dates, search
records, and identify expired or soon-to-expire warranties.

## Features

- Add product warranty details
- View all warranties
- Search by product name or brand
- View warranties expiring within 30 days
- View expired warranties
- Delete warranty records
- Store records in JSON format

## Technologies Used

- Python
- JSON
- Date and time handling
- File handling
